Token flow — project stack + recursive left-tree (mockup v5)

Projects pile vertically (one wide row each, never tiled); the tiers inside a project tile into the four status lanes with Working on the left. A thread's children are contained inside its own card, and the containment recurses: parent → child → grandchild. The left-tree splits at every level, exactly as threads branch from projects. The branch into a thread carries just that thread's own flow — never the subtree sum — while the sum appears only as the card's total. There is no sky beam.
