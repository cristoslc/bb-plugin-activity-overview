# Contributing

## Human process

- Branch names: `feat/…`, `fix/…`, `chore/…`. Commits: conventional prefixes (`feat:`, `fix:`, `chore:`).
- Open issues before large changes; PRs reference an issue when one exists.
- Review: one maintainer review suffices for this plugin; merge squash.

## Agent requirements

- Link to and follow the project `AGENTS.md`.
- Test command (see AGENTS.md `## Test command`) must pass before every PR.
- Agent-originated fixes MUST arrive with reproduction steps and a failing test added in the same change.
- Update `CHANGELOG.md`'s Unreleased section in the same PR.
